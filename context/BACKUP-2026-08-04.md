## Decisiones de esta sesión (por qué está así, no de otra forma)
- **anime.js instalado**, no bklit-ui — bklit-ui es un registro de shadcn
  para React, requiere Node.js + build. Incompatible con "sin build step".
  Si en el futuro se necesitan gráficos de datos reales, Chart.js vía CDN
  es la alternativa compatible (no instalado todavía, solo evaluado).
- **Easing de anime.js**: `cubicBezier(...)` camelCase, NUNCA
  `cubic-bezier(...)` estilo CSS — rompe la librería sin error claro.
- **`--spring: cubic-bezier(.34,1.32,.64,1)`** es el valor final acordado
  después de 3 rondas de ajuste (empezó en 1.56, se bajó a 1.14 por
  "muy fuerte", volvió a subir a 1.32 por "muy plano" — este es el punto
  medio confirmado).
- **Temblor de cards vecinas**: reducido ~8x de la versión original
  (de ±2px a ±0.6px) — el efecto está pero es casi imperceptible a propósito.
- **Emojis**: prohibidos como íconos de UI en toda página activa. Confirmado
  limpio en Chek/DollarCity/Blockchain (quedan solo `● → ← ↗ ↙` que son
  tipografía estándar, no emoji).
- **Chek bug real arreglado**: flujo `'pay-select'` no existía, el real
  era `'payment'` — típeo, no error de lógica.
