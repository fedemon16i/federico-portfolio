The case

Where 2D design meets an immersive world.

A 3D blockchain platform demanded flows that felt native in space — without losing the clarity of 2D product design.

01 · The space

A map you can own.

Every user gets a space with a 3D map at its heart. My job: make 2D product patterns feel native inside it.

  • Mobile-first designs translated to desktop
  • Spatial UI best practices benchmarked from immersive apps

02 · Feature · Set map pin

Icon, image — or a 3D asset.

The pin system I pioneered: mark a point of interest as a flat icon, a photo, or a full 3D object from the library.

  • 2D/3D map feature validated via client-led user testing
  • Figma prototypes bridged with 3D animation tools

03 · Feature · Points of interest

Places that carry content.

A POI is not a dot — it holds names, descriptions, tags, feeds. Creation and consumption designed as one loop.

  • POI creation form — image, actions, tags
  • Visitor view with content tabs and feeds

04 · Feature · Browse & search

From one pin to a whole world.

Lists, search and management for spaces that grow — the 2D backbone that keeps the 3D world navigable.

  • Multiple-POI list and reordering
  • Place search with native map results
