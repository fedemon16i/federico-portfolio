01 Problem

A map with depth — and no clear way to own a place inside it.

Markers on flat maps do not feel like places you made. Content lived in other apps. Owners could place a pin, but visitors never met the media. The break was between spatial intent and published experience.

02 Spatial

Codename Spatial

A social experiment: visit 3D spaces, enter an object that holds a map, and leave stories inside it — not a flat pin on a 2D surface.

02b Constraints

Type over terrain

City stays alive under the UI. Headlines and drawers never compete with the mesh for contrast.

Drawer owns the bottom

While configuring a pin or media, the sheet covers the tab bar so chrome cannot steal the next tap.

One continuous loop

Place in space, attach media, open as a visitor — without leaving the map for another app.

public class POIPlacer : MonoBehaviour {
  float holdTime = 0.55f;
  void Update() {
    if (LongPressOnGround(holdTime))
      PromptConfirmAddress();
  }
  void PromptConfirmAddress() {
    MapsConfirm.Show(selected.lat, selected.lng);
  }
}
