Framework laws

One system for every future project

Measure 920 max — BC is the reference. Home, EY, Chek, Contact, DS obey the same.
Hero start Shared padding under nav so case titles align.
Player Chrome + one stage. Text full stage → UI window → caption gradient/blur only.
Fit scale min(host/design)×~0.9 — ~90% of mock UI visible; no crop; not transparency.
Mobile stage Explicit height (~52dvh). Never collapse to 0 (empty PI).
Phone Ratio 9/19.5; size from host; entire device in view.
Forbidden Full-bleed content width · solid gray caption bar · scale on stage host · fixed 420 square stage · independent width/height stretch on phone.
