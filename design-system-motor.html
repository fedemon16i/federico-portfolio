Design system · motion

Animation motor

One CSS marker per page: MOTOR SAFE v6. Skills, EY, and Blockchains share caption language; each keeps its own animation engine.

Shared rules

  • Caption — left/right/bottom: 0, gradient + blur, stage padding: 0.
  • Measure — content max 920px.
  • Controls — row, ~32px pills, arrows ~28px @ 55% opacity, prog 3px.
  • Viewport — width=device-width, initial-scale=1, viewport-fit=cover.
