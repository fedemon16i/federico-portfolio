# EY Fabric — design framework notes

## Role in system
Accent: `--acc-ey` (#ffe600). Graphic: catalog wireframe + cursor (not Three.js).

## Sections (case)
1. Hero — compact, metric reel optional, stack **icochips** (Pendo, Figma, Maze…)
2. Problem / context narrative
3. **Product intelligence** — shared narrative **player** (beats: Measure → Analyze → Research → Understand → Design → Govern)
4. Process / decisions
5. Prev / Next project

## Components used
- Shared player chrome (label, prev, play, next, chips)
- Typewriter → device/UI reenactment
- Stack icochips (colored)
- Section boxes, metric reel
- No emoji

## Unique only
- Yellow accent and EY mark
- Catalog / Pendo loop copy
- Wireframe hero language on cards

## A11y
- Focusable beats and controls
- Text ≥16px body target
