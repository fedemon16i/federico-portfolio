Animation kit

Wireframes, not stock screenshots

Every process animation in this portfolio — EY's catalog flow, the home page's "watch usage" beat — uses the same wireframe primitives: lines instead of real text, a visitor cursor, a funnel for drop-off. It protects confidential content and reads faster than a busy screenshot.

Continue
Lines, not text — protects real client content while still reading as "a real screen."
One visitor cursor style — a pulsing ring, used everywhere someone needs to "walk through" a flow.
Real tool logos only — Figma, Pendo, Qualtrics as actual inline SVGs, never a generic icon-font glyph.
