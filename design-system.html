What drives beats

State machine

idle → typing → holding → device → next. runId guards stale timeouts. prefers-reduced-motion respected.

CSS + timers

No heavy engine. after()/setTimeout sequences, CSS transitions, occasional canvas/WebGL only in Blockchains 3D.

Timing (visitors)

Playback pace

Narrative typewriter + beat holds tuned for people browsing a portfolio — not a product demo marathon.

A · Balanced (shipped)

Type ~26–28ms/char · beat holds ~0.5–0.9s median · interactions responsive. Best default for recruiters.

B · Snappy

~15% faster narrative · shorter holds. Use if analytics show drop-off mid-player.
